# 国内期货品种对照表

同一批国内期货品种在**东方财富 / 新浪财经 / 文华财经**三个行情平台上的名称差异一览，并标注每个品种所属的期货交易所。

做行情对接、多平台数据比对、爬虫映射时，最常见的坑就是「同一个品种，三个站点三种叫法」。比如 `ag`：东方财富叫「沪银」，新浪财经叫「白银」，文华财经叫「沪银」；`ad` 在东方财富是「铸造铝」，新浪财经是「铸造铝合金」，文华财经是「铝合金」。这份表就是用来一把过掉这些映射的。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `国内期货品种对照表.xlsx` | 主数据表，单 sheet（`国内期货品种对照`），95 个品种 |

## 字段

| 列 | 字段名 | 说明 |
| --- | --- | --- |
| A | 品种代码 | 交易所标准品种代码（如 `ag`、`AP`、`IF`），大小写保留原始写法 |
| B | 品种名称（东方财富） | 东方财富行情端的显示名 |
| C | 品种名称（新浪财经） | 新浪财经行情端的显示名 |
| D | 品种名称（文华财经） | 文华财经行情端的显示名 |
| E | 所属期货交易所 | 上海期货交易所 / 大连商品交易所 / 郑州商品交易所 / 上海国际能源交易中心 / 中国金融期货交易所 / 广州期货交易所 |

表内第 1 行是标题行，第 2 行是字段行，数据从第 3 行开始。

## 覆盖的交易所

- 上海期货交易所（SHFE）
- 上海国际能源交易中心（INE）
- 大连商品交易所（DCE）
- 郑州商品交易所（CZCE）
- 中国金融期货交易所（CFFEX）
- 广州期货交易所（GFEX）

## 使用方式

```python
import openpyxl

wb = openpyxl.load_workbook("国内期货品种对照表.xlsx", data_only=True)
ws = wb["国内期货品种对照"]

# 建映射：代码 -> {平台: 名称}
mapping = {}
for code, em, sina, wenhua, exch in ws.iter_rows(min_row=3, values_only=True):
    if not code:
        continue
    mapping[code] = {"东方财富": em, "新浪财经": sina, "文华财经": wenhua, "交易所": exch}

print(mapping["ag"])
# {'东方财富': '沪银', '新浪财经': '白银', '文华财经': '沪银', '交易所': '上海期货交易所'}
```

## 注意

- 品种代码大小写沿用各交易所的习惯写法（郑商所多为大写如 `AP`、`CF`，其余多为小写），跨平台拼接接口时建议先 `lower()` 归一化再匹配。
- 平台显示名会随业务调整变化，若发现与最新行情端不一致，欢迎提 Issue 或 PR 修正。
